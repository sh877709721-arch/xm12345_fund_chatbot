# 医疗保险用户意图识别MCP工具

## 概述

这是一个专为医疗保险领域设计的智能用户意图识别和问题改写MCP（Model Context Protocol）工具。该工具能够：

- 🔍 **智能意图识别**：将用户问题自动分类到三级医疗保险目录体系
- ✏️ **问题改写优化**：将口语化问题转化为专业医保术语
- 📊 **置信度评分**：为每个识别结果提供可信度评估
- 📦 **批量处理**：支持多个问题的批量意图识别

## 功能特性

### 🎯 核心功能

1. **三级分类体系**
   - 一级分类：职工基本医疗保险、城乡居民医疗保险、生育保险、其他医药政策
   - 二级分类：参保缴费、医疗待遇、办事指南等
   - 三级分类：具体业务类型，如参保对象、缴费标准、报销办理等

2. **智能匹配算法**
   - 基于关键词的层级匹配
   - 正则表达式模式匹配
   - 同义词和近义词处理
   - 置信度加权计算

3. **问题改写功能**
   - 添加专业术语
   - 补充缺失的关键信息
   - 根据意图类型优化表述

## 工具接口

### 1. recognize_user_intent(query: str)

识别单个用户问题的意图。

**参数：**
- `query`: 用户的原始查询文本

**返回示例：**
```json
{
  "success": true,
  "data": {
    "first_level": "职工基本医疗保险",
    "second_level": "办事指南",
    "third_level": "医疗费用报销办理",
    "confidence": 0.85,
    "action": "医疗费用报销",
    "rewritten_query": "职工基本医疗保险：医保怎么报销 报销流程",
    "timestamp": "2025-11-14T10:30:00"
  }
}
```

### 2. rewrite_medical_query(query: str)

改写医疗保险相关问题。

**参数：**
- `query`: 原始查询文本

**返回示例：**
```json
{
  "success": true,
  "data": {
    "original_query": "生孩子有什么补贴",
    "rewritten_query": "生育保险：生孩子有什么补贴 生育津贴待遇",
    "intent": {
      "first_level": "生育保险",
      "second_level": "生育待遇",
      "third_level": "生育津贴待遇"
    },
    "confidence": 0.92,
    "timestamp": "2025-11-14T10:30:00"
  }
}
```

### 3. get_intent_taxonomy()

获取完整的意图分类体系。

**返回示例：**
```json
{
  "success": true,
  "data": {
    "taxonomy": {
      "职工基本医疗保险": {
        "参保缴费": {
          "参保对象": ["职工", "单位职工", "在职人员"],
          "缴费标准": ["缴费", "费用", "标准", "基数"]
        }
      }
    },
    "total_categories": 4,
    "timestamp": "2025-11-14T10:30:00"
  }
}
```

### 4. batch_intent_recognition(queries: list)

批量识别多个查询的意图。

**参数：**
- `queries`: 查询文本列表

**返回示例：**
```json
{
  "success": true,
  "data": {
    "results": [
      {
        "query": "职工医保怎么报销",
        "success": true,
        "first_level": "职工基本医疗保险",
        "second_level": "办事指南",
        "third_level": "医疗费用报销办理",
        "confidence": 0.85,
        "action": "医疗费用报销",
        "rewritten_query": "职工基本医疗保险：医保怎么报销 报销流程"
      }
    ],
    "total_queries": 1,
    "successful_recognition": 1,
    "timestamp": "2025-11-14T10:30:00"
  }
}
```

## 分类体系

### 📋 完整的三级分类目录

#### 职工基本医疗保险
- **参保缴费**
  - 参保对象 | 缴费标准 | 参保缴费方式
  - 参保缴费纠纷处理 | 重复参保处理 | 退费
- **医疗待遇**
  - 待遇生效时间 | 连续参保机制 | 医保账户划拨
  - 大病医保 | 医疗救助 | 待遇标准 | 就医使用
- **办事指南**
  - 医疗费用报销办理 | 异地就医备案办理
  - 家庭共济办理 | 医保退休办理 | 个人账户一次性支取办理
- **转移接续手续办理**

#### 城乡居民医疗保险
- **参保缴费**
  - 参保对象 | 缴费标准 | 参保缴费方式
  - 重复参保 | 退费
- **医疗待遇**
  - 待遇生效时间 | 参保长效机制 | 医保账户划拨
  - 大病医保 | 医疗救助 | 待遇标准 | 就医使用
- **办事指南**
  - 医疗费用报销办理 | 异地就医备案办理
  - 家庭共济办理 | 转移接续手续办理

#### 生育保险
- **参保缴费**
  - 参保对象 | 缴费标准 | 参保缴费方式 | 参保缴费纠纷处理
- **生育待遇**
  - 生育津贴待遇 | 男职工未就业配偶生育医疗费用待遇 | 其他待遇
- **办事指南**
  - 生育津贴办理 | 男职工未就业配偶生育医疗费用办理

#### 其他医药政策
- **药品（含项目、耗材）政策**
  - 药品目录 | 医疗服务项目目录 | 医用耗材目录
- **DRG收费及按病种收费政策**
  - 厦门市定点医疗机构就医 | 省内异地定点医疗机构就医
- **辅助生殖政策**
  - 福建省辅助生殖类医疗服务价格项目及省属公立医院项目价格表
  - 辅助生殖医保支付政策
- **补充医疗保险**
  - 惠厦保
- **长期护理险政策**


### 典型使用场景

#### 场景1：识别用户咨询意图
```python
from app.core.mcp.intent import recognize_user_intent

query = "灵活就业人员医保怎么缴费？"
result = recognize_user_intent(query)
# 返回：职工基本医疗保险 > 参保缴费 > 参保缴费方式
```

#### 场景2：优化用户问题
```python
from app.core.mcp.intent import rewrite_medical_query

query = "生孩子能领多少钱？"
result = rewrite_medical_query(query)
# 返回："生育保险：生孩子能领多少钱 生育津贴待遇"
```

#### 场景3：批量处理客服问题
```python
from app.core.mcp.intent import batch_intent_recognition

queries = [
    "医保卡丢了怎么办？",
    "异地就医怎么备案？",
    "生育津贴申请流程"
]
result = batch_intent_recognition(queries)
# 批量识别所有问题的意图
```

## 技术实现

### 🔧 核心算法

1. **文本预处理**
   - 小写转换和空格标准化
   - 同义词替换和规范化

2. **模式匹配**
   - 基于正则表达式的高精度匹配
   - 覆盖常见查询模式

3. **层级匹配**
   - 三级分类体系的递进式匹配
   - 加权置信度计算

4. **查询改写**
   - 基于识别结果的专业术语添加
   - 上下文相关的关键词补充

### 📊 置信度计算

置信度采用加权计算方式：
- 一级分类权重：30%
- 二级分类权重：30%
- 三级分类权重：40%

### 🧠 同义词处理

系统内置了丰富的同义词词典：
- 职工 → 员工、在职人员、工作者
- 居民 → 城乡居民、城镇居民、农村居民
- 报销 → 费用报销、理赔、结算
- 异地 → 外地、其他城市、非参保地
